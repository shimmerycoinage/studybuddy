# Серверная часть

Место для реализации SB-5. Исполняемый каркас пока не создан.

По [SB-5](https://linear.app/ekaterina-rogozinnikova/issue/SB-5/karkas-bekenda-m) сервер использует FastAPI, PostgreSQL, SQLAlchemy и миграции Alembic. Docker Compose должен поднимать сервер и базу командой `docker compose up`, а `/health` — возвращать `ok`.

## Запланированные части

[SB-6] регистрация (имя, email, пароль), вход, текущий пользователь; bcrypt и JWT.

### Бэкенд и PostgreSQL
Запустите Docker Desktop и откройте powershell в корне репозитория, где лежит `docker-compose.yml`.
1. Сгенерируйте секретный ключ для подписи JWT. Для этой команды нужен Python 3.

   ```powershell
   python -c 'import secrets; print(secrets.token_hex(32))'
   ```
2. Создайте файл `.env` рядом с `docker-compose.yml`. Вставьте сгенерированную строку после `JWT_SECRET=` без пробелов.

   ```dotenv
   JWT_SECRET=ваш_сгенерированный_ключ
   ```
3. Соберите и запустите бэкенд и PostgreSQL.

   ```powershell
   docker compose up --build -d backend
   ```

   При запуске бэкенд автоматически применит миграции базы данных.

### Проверка регистрации и входа

Откройте [Swagger](http://localhost:8000/docs) и используйте тестовые данные.

1. Через `POST /register` создайте аккаунт с новым email. Ожидаемый код — `201`.
2. Через `POST /login` войдите с тем же email и паролем. Ожидаемый код — `200`. Скопируйте значение `access_token` из ответа.
3. Нажмите **Authorize** и вставьте токен без кавычек и без слова `Bearer`. Затем выполните `GET /me`. Ожидаемый код — `200`, в ответе будут `id`, `name` и `email` вашего аккаунта.

4. Откройте [проверку состояния](http://localhost:8000/health). Ожидаемый ответ — `{"status":"ok"}`.
