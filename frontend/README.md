# Клиентская часть

Место для реализации SB-3. Исполняемый каркас пока не создан.

По прочитанной задаче SB-3: Vite, несколько HTML-страниц (вход, регистрация, группы), React для вопросов и редактора, ESLint и Prettier.

Предусмотрены каталоги `pages`, `components`, `api`, `hooks`, `styles`. Они появятся вместе с исходными файлами каркаса.

В SB-4 указан шрифт Onest и CSS-переменные для дизайн-токенов. Значения токенов нужно получить из спецификации; макеты пока не созданы.

После реализации и проверки добавьте сюда точные команды установки, запуска и сборки.
