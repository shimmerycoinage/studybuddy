# Клиентская часть

Реализация клиентской части StudyBuddy

## Текущий статус
- [SB-3]: Каркас фронтенда на Vite + React. Структура каталогов `pages`, `components`, `api`, `hooks`, `styles` подготовлена.
- [SB-4]: Дизайн-токены (CSS-переменные) и шрифт Onest подключены и используются в `frontend/src/styles/style.css`. Ручные значения цветов и размеров убраны.
- [SB-7]: Экраны входа и регистрации. Реализована валидация на лету, обработка ошибок API, состояние загрузки кнопки и управление с клавиатуры.


## Установка и запуск

1. Перейдите в папку фронтенда:
   ```bash
   cd frontend
2. Установите зависимости:
    npm install
3. Запустите сервер разработки:
    npm run dev
4. Откройте браузер по адресу: http://localhost:5173/

## Запланированные части

- SB-8: состояние авторизации и защищённые страницы.
- SB-9–SB-10: UI-kit и общий каркас с боковым меню 240 px.
- SB-12–SB-14: группы, создание и вступление по коду, управление участниками.
- SB-16–SB-17: список вопросов и страница вопроса с ответами.
- SB-19: материалы, загрузка файлов и скачивание.
- SB-21–SB-22: TipTap + Yjs, панель редактора, присутствие, курсоры и комментарии.
- SB-24: встречи и Jitsi Meet; присоединение за 15 минут до начала.
- SB-25–SB-26: адаптив на 375, 768 и 1280 px; Vitest для Button и формы входа.

Button и Input должны иметь общие CSS-классы, чтобы их можно было использовать также в обычном HTML. Подробные критерии всех задач — в [плане](../docs/REQUIREMENTS.md).
