# Клиентская часть

Место для реализации SB-3. Исполняемый каркас пока не создан.

По [SB-3](https://linear.app/ekaterina-rogozinnikova/issue/SB-3/karkas-frontenda-m): Vite, несколько HTML-страниц (вход, регистрация, группы), React для вопросов и редактора, ESLint и Prettier.

Предусмотрены каталоги `pages`, `components`, `api`, `hooks`, `styles`. Они появятся вместе с исходными файлами каркаса.

В SB-4 указан шрифт Onest и CSS-переменные для дизайн-токенов. Значения токенов нужно получить из спецификации; макеты пока не созданы.

После реализации и проверки добавьте сюда точные команды установки, запуска и сборки.

## Запланированные части

- SB-7–SB-8: формы входа и регистрации, состояние авторизации и защищённые страницы.
- SB-9–SB-10: UI-kit и общий каркас с боковым меню 240 px.
- SB-12–SB-14: группы, создание и вступление по коду, управление участниками.
- SB-16–SB-17: список вопросов и страница вопроса с ответами.
- SB-19: материалы, загрузка файлов и скачивание.
- SB-21–SB-22: TipTap + Yjs, панель редактора, присутствие, курсоры и комментарии.
- SB-24: встречи и Jitsi Meet; присоединение за 15 минут до начала.
- SB-25–SB-26: адаптив на 375, 768 и 1280 px; Vitest для Button и формы входа.

Button и Input должны иметь общие CSS-классы, чтобы их можно было использовать также в обычном HTML. Подробные критерии всех задач — в [плане](../docs/REQUIREMENTS.md).
